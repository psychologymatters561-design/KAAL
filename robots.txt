# Everything here is open to everything. There is no hidden directory, no
# page written for a crawler that a reader does not get, and nothing served
# differently depending on who is asking.
#
# The crawlers below are named individually rather than left to the wildcard
# on purpose. The wildcard already allows them all, so naming one grants it
# nothing it did not have — what the list does is state intent, and stop a
# future Disallow from taking out something that matters without anybody
# noticing which. Several of these agents are opt-in in practice, plenty of
# sites block them by accident, and a brand whose whole argument has to be
# read before it lands would rather be quoted accurately than not quoted.

# ── Common Crawl ───────────────────────────────────────────────────────
# Named on its own because it is the single highest-leverage agent on this
# list and the easiest to forget. A large share of what language models and
# smaller search engines know about any site arrives through this crawl,
# second hand, long after the fact. Being absent from it is being absent
# from the answers.
